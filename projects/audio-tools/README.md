# NOIR Audio

A clean black-and-white collection of browser-based audio tools.

## Included tools

- 8D Audio
- Bass Booster
- Vocal Remover
- Reverb
- Echo / Delay
- Speed Changer
- Reverse Audio
- Normalize
- Fade In / Out

Audio processing happens locally in the browser with the Web Audio API. Files are not uploaded to a server.

## Run locally

Open `index.html` directly, or serve the folder with any static HTTP server.

## Deploy

This project is static and works on Vercel with no build step.
